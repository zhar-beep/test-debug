[A] RootBridge.kt (`app/src/main/java/com/kasane/shell/RootBridge.kt`):
--------------------------------------------------------------------------------
- Language: Kotlin
- Concurrency: `CoroutineScope(Dispatchers.IO + SupervisorJob())`
- Security Libraries:
  * `com.topjohnwu.superuser:core:5.2.2` (libsu)
  * `com.scottyab:rootbeer-lib:0.1.0` (RootBeer)
- Key Exposed Javascript Methods:
  1. `checkRoot(): Boolean`:
     Checks `Shell.isAppGrantedRoot()` followed by fallback `su -c "id"` UID 0 check.
  2. `runRootDiagnostics(): String`:
     Returns JSON containing RootBeer heuristic checks, libsu grant status, UID 0 verification, `ksud -V` detection, SuSFS kernel status, SELinux enforcement, and `/data/local/tmp` read/write capability test (`.kasane_test`).
  3. `getDeviceSpecs(): String`:
     Extracts hardware model via `Build.MODEL`, Android OS version via `Build.VERSION.RELEASE`, active slot via `getprop ro.boot.slot_suffix`, and kernel version via `/proc/version` file reading (falling back to `uname -r`).
  4. `listDirectory(dirPath: String): String`:
     Sanitizes target path to `/data/local/tmp`. Executes `su -c "mkdir -p /data/local/tmp && chmod 777 /data/local/tmp"` to guarantee folder availability, then executes `su -c "ls -la \"$safePath\""`, parses rows into JSON array with name, path, isDirectory, permissions, octal, size, and isScript.
  5. `changePermissions(filePath: String, octal: String): Boolean`:
     Executes `su -c "chmod $octal \"$filePath\""` and returns boolean success.
  6. `runScript(scriptPath: String)`:
     Launches background coroutine on `Dispatchers.IO`. Runs `su -c "chmod +x \"$scriptPath\""`. Spawns `ProcessBuilder("su", "-c", "sh \"$scriptPath\"")`. Starts concurrent coroutines reading `process.inputStream` and `process.errorStream` line-by-line, formatting via `categorizeLine()`, and sending to WebView via `webView.evaluateJavascript("window.onNativeLogReceived(...)")`. Upon completion, triggers `window.onNativeExecutionFinished(exitCode)`.
  7. `killProcess(): Boolean`:
     Calls `currentProcess?.destroyForcibly()` to immediately terminate active process (Ctrl+C equivalent).
